QR GUARD — COLLEGE PROTOTYPE

How to run:
1. Open this folder in VS Code.
2. Install the Live Server extension in VS Code (recommended).
3. Right-click index.html -> Open with Live Server.
4. Use Dashboard, Scan, Generate, Safety Guide and Settings from the top navigation.

Important:
- Image QR scanning uses the jsQR library from jsDelivr.
- QR generation uses QRCode.js from jsDelivr.
- Therefore image scanning/generation needs internet access unless the libraries are downloaded locally.
- Camera access works best through Live Server (localhost).
- This is an educational prototype, not a guarantee that a website is safe.
